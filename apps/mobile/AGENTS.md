# Mobile

Expo React Native app for Android and iOS. Keep fridge, saved recipes, and shopping list device-local through `src/state/useLocalState.ts`; there is no account or sync layer in MVP.

- API base URL is `EXPO_PUBLIC_API_URL`.
- Checks: `npm run typecheck`, `npm test`, `npm run build`.
- Preserve the five-tab flow and recipe detail/cooking flow when changing UI.
