# Konto przechowuje minimalny identyfikator użytkownika

## Decyzja

Konto użytkownika przechowuje wyłącznie wewnętrzne rozpoznanie konta i techniczne powiązanie z tożsamością logowania Google. Nie przechowujemy imienia, adresu e-mail, zdjęcia ani innych danych profilu Google.

## Powód

Appetyt potrzebuje stabilnego rozpoznania osoby, aby w przyszłości przypisać recenzję do konta i umożliwić jej dalsze używanie po wygaśnięciu sesji. Nie potrzebuje do tego społecznego profilu użytkownika. Ograniczenie zakresu zmniejsza ryzyko prywatności i zakres danych do usunięcia.

Techniczny identyfikator Google jest nadal pseudonimową daną osobową, więc nie traktujemy tego rozwiązania jako całkowicie anonimowego.

## Konsekwencja

Nie wolno dodawać e-maila, nazwy ani zdjęcia tylko dlatego, że Google zwraca je w odpowiedzi OAuth. Jeśli w przyszłości funkcja będzie wymagała dodatkowych danych, będzie to osobna decyzja domenowa.
